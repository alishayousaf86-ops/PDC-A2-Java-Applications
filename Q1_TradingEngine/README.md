# Q1 - Trading Engine

## Purpose
This application demonstrates trading orders and market quotes using Java classes.

## Working
- TradeEvent represents a general trading event.
- FIXOrderEvent stores order information.
- ReutersQuoteEvent stores market bid and ask prices.
- TradingEngineApp creates objects and displays their information.
- The program calculates the order fee, total cost, and bid-ask spread.

## Result
The application displays order details and market quote information.
