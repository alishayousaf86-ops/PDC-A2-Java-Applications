# PDC Assignment 2 — Java Applications
This repository contains seven Java applications developed for the Parallel and Distributed Computing (PDC) assignment.
## Applications
1. **Trading Engine:** Processes trading orders and market quotes.
2. **Stack and Queue:** Uses stack and queue data structures to check palindrome input.
3. **Multithreading:** Demonstrates concurrent execution using Java threads.
4. **Fork/Join:** Calculates total risk using parallel tasks.
5. **Parallel Search:** Finds minimum and maximum values using multiple threads.
6. **Concurrent Collections:** Compares synchronized maps with ConcurrentHashMap.
7. **Cache Locality:** Compares row-major and column-major array access.
## Technologies
- Java
- Object-Oriented Programming
- Multithreading and concurrency
- Fork/Join framework
- Collections and arrays
## Running an Application
Open the relevant application folder in the terminal and run:

javac *.java
java MainClassName


Replace `MainClassName` with the main class for that application.

Each application can be compiled and executed separately.
