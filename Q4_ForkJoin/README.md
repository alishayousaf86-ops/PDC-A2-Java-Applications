# Q4 - Fork/Join Risk Calculator

## Purpose
This application calculates total risk using Java's Fork/Join framework.

## Working
- An array stores risk values.
- RecursiveTask divides the work into smaller parts.
- Fork and join help process the parts in parallel.
- System.nanoTime() measures execution time.

## Expected Result
Total Risk: 2.49975E7
Execution time may vary between runs.
