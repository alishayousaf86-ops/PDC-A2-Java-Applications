\# PDC Java Applications



\## Project Overview



This project contains seven Java applications demonstrating parallel and distributed computing concepts.



\## Applications



1\. \*\*Trading Engine\*\* — Processes stock orders and market quotes.

2\. \*\*Stack and Queue\*\* — Checks whether a word is a palindrome.

3\. \*\*Multithreading\*\* — Runs telemetry and log-processing tasks concurrently.

4\. \*\*ForkJoin\*\* — Calculates a sum using the ForkJoin framework.

5\. \*\*Parallel Search\*\* — Finds minimum and maximum values using threads.

6\. \*\*Concurrent Collections\*\* — Compares synchronized and concurrent maps.

7\. \*\*Cache Locality\*\* — Compares row-wise and column-wise array traversal.



\## How to Run



1\. Open the required application folder in the terminal.

2\. Compile the Java files using `javac \*.java`.

3\. Run the main class using `java ClassName`.



Replace `ClassName` with the main class of the application.



\## Testing



Compile each application before running it. Check its output and verify that it produces the expected results.
