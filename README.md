# PDC Assignment 2 - Java Applications

This repository contains seven Java applications for Parallel and Distributed Computing.

## Applications

1. Trading Engine - Processes trading orders and market quotes.
2. Stack and Queue - Checks palindrome input.
3. Multithreading - Demonstrates concurrent threads.
4. Fork/Join - Calculates total risk using parallel tasks.
5. Parallel Search - Finds minimum and maximum values.
6. Concurrent Collections - Compares synchronized maps.
7. Cache Locality - Compares row-major and column-major access.

## Technologies
- Java
- Object-Oriented Programming
- Multithreading
- Fork/Join Framework
- Concurrent Collections

## How to Run
Open the required application folder and compile using javac *.java.
Run the application using java followed by its main class name.
